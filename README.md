## 📌 Sobre este material

Este guia foi criado para estudantes que estão tendo seu **primeiro contato com Git e GitHub**. O objetivo é desmistificar o controle de versão com linguagem acessível, analogias do cotidiano e desafios práticos progressivos.

Ele faz parte das iniciativas educacionais da **Virada no Café** — movimento de educação em tecnologia voltado à democratização do acesso digital, especialmente para mulheres de comunidades periféricas.

## 🎯 Desafios incluídos

Os desafios foram pensados para serem feitos em sequência, do mais simples ao mais desafiador:

1. **Meu Primeiro Repositório** `fácil` — `git init`, `git add`, `git commit`
2. **Subindo para o GitHub** `fácil` — conectar o repositório local ao remoto com `git push`
3. **Histórico de Versões** `fácil` — criar múltiplos commits com mensagens significativas
4. **Explorando Branches** `médio` — criar branch, commitar e fazer merge
5. **Clone & Pull Request** `médio` — colaborar com o repositório de um colega
6. **Portfólio no GitHub Pages** `avançado` — publicar um site gratuito na internet

## 🚀 Como usar

### Opção 1 — Abrir direto no navegador

Baixe o arquivo `guia_git_github_iniciantes.html` e abra com qualquer navegador. O guia funciona completamente **offline**.

### Opção 2 — Clonar este repositório

```bash
git clone https://github.com/seu-usuario/guia-git-github-iniciantes.git
cd guia-git-github-iniciantes
```

Depois abra o `guia_git_github_iniciantes.html` no navegador.

## 🤝 Contribuindo

Encontrou um erro? Quer sugerir um novo desafio ou melhorar alguma explicação?

1. Faça um fork deste repositório
2. Crie uma branch: `git checkout -b melhoria/sua-sugestao`
3. Faça suas alterações e commit: `git commit -m "Melhora explicação de branches"`
4. Abra um Pull Request — ficarei feliz em revisar! 🙌
